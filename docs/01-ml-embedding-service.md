# ML Embedding Service

ML Embedding Service превращает текст статьи в числовой вектор — эмбеддинг. Этот вектор описывает смысл текста и используется следующими сервисами для определения похожих текстов.

## Вход и выход

- **Вход:** текст статьи.
- **Выход:** эмбеддинг документа и версия использованной модели.

## Как работает

1. Сервис получает текст статьи.
2. Если текст длинный, он делится на небольшие фрагменты.
3. Модель BERT создаёт эмбеддинг для каждого фрагмента.
4. Сервис объединяет их в один эмбеддинг статьи и возвращает результат.

## Взаимодействие

Оркестратор вызывает сервис по gRPC. Полученный эмбеддинг передаётся в сервис LSH Hash для поиска похожих документов.

## Минимальная сборка: 

- Python-сервис в Docker;
- одна gRPC-команда для получения эмбеддинга;
- health-check;
- тесты на одинаковый текст и перефразированные версии текста.
